# Pantry Packers — Digital Business Cards

Public presentation only. Employee contact details are retrieved from published Supabase records on page load. Editors and full source code remain in private `PantryPackers/employee-cards`.

GitHub Pages publishes this repository's main branch root. The project exposes only a Supabase publishable key, never a secret or service-role key. RLS protects the Supabase database. This repository and its contents are publicly visible; no reuse license is granted.
